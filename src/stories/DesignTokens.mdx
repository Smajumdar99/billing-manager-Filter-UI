# Design Tokens

Design tokens are the foundational elements of our design system. They ensure consistency across all components and provide a single source of truth for design decisions in the DrCloud EHR system.

## Color Palette

### Primary Colors

**Primary Blue**: `#2563eb` (Blue-600)
- Main brand color
- Used for primary buttons, links, and key UI elements
- High contrast for accessibility

**Primary Hover**: `#1d4ed8` (Blue-700)
- Hover state for primary elements
- Maintains accessibility standards

**Primary Light**: `#dbeafe` (Blue-100)
- Background for subtle emphasis
- Cards and secondary backgrounds

### Medical Context Colors

**Success Green**: `#16a34a` (Green-600)
- Positive actions, success states
- Medication approvals, completed tasks

**Warning Orange**: `#ea580c` (Orange-600)
- Caution states, pending actions
- Medication warnings, incomplete forms

**Danger Red**: `#dc2626` (Red-600)
- Critical alerts, destructive actions
- Emergency indicators, error states

**Info Blue**: `#0284c7` (Sky-600)
- Informational messages
- System notifications, help text

### Neutral Colors

**Text Primary**: `#1f2937` (Gray-800)
- Primary text color
- Headers, body text

**Text Secondary**: `#6b7280` (Gray-500)
- Secondary text
- Captions, helper text

**Text Muted**: `#9ca3af` (Gray-400)
- Disabled text
- Placeholder text

**Border**: `#e5e7eb` (Gray-200)
- Default border color
- Input borders, dividers

**Background**: `#f9fafb` (Gray-50)
- Page background
- Card backgrounds

## Shadows

### Elevation Levels

**Small**: `0 1px 2px 0 rgba(0, 0, 0, 0.05)`
- Subtle depth for cards

**Medium**: `0 4px 6px -1px rgba(0, 0, 0, 0.1)`
- Default card shadow

**Large**: `0 10px 15px -3px rgba(0, 0, 0, 0.1)`
- Modals, dropdowns

**Extra Large**: `0 25px 50px -12px rgba(0, 0, 0, 0.25)`
- Overlays, important modals

## Accessibility Standards

### Color Contrast
- **Normal text**: Minimum 4.5:1 contrast ratio
- **Large text**: Minimum 3:1 contrast ratio
- **Interactive elements**: Minimum 3:1 contrast ratio

### Touch Targets
- **Minimum size**: 44px × 44px (WCAG AAA)
- **Recommended**: 48px × 48px for mobile interfaces

### Focus Indicators
- **Ring width**: 2px
- **Ring color**: Primary blue with 50% opacity
- **Ring offset**: 2px from element

## Medical Environment Considerations

### High Contrast Mode
All color combinations maintain readability in high contrast mode for:
- Users with visual impairments
- Bright medical lighting conditions
- Older display technologies

### Color Blindness Support
- Never rely on color alone to convey information
- Use icons, labels, and patterns alongside color
- Test with color blindness simulators

### Emergency Contexts
- **Critical alerts**: Red background with white text
- **Emergency buttons**: High contrast, large touch targets
- **Time-sensitive actions**: Clear visual hierarchy

### CSS Custom Properties

```css
:root {
  /* Colors */
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-success: #16a34a;
  --color-warning: #ea580c;
  --color-danger: #dc2626;
  
  /* Typography */
  --font-size-base: 1rem;
  --line-height-normal: 1.5;
  
  /* Spacing */
  --spacing-4: 1rem;
  --spacing-8: 2rem;
  
  /* Borders */
  --border-radius: 0.25rem;
  --border-width: 1px;
}
```
